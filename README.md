# CINEVAULT

<p>
  A movie discovery website built with React, Redux, Tailwind CSS, and the TMDB API.
</p>

</div>

---

<h2>Why I Built This</h2>

<p>
  I often get movie recommendations from friends, social media, or just come across movies that I want to watch later. I used to write their names down in a notebook, but keeping track of them that way wasn't really convenient.
</p>

<p>
  So I decided to build CINEVAULT — a place where I could search for movies, explore new ones, and save the movies I want to watch later instead of writing them down every time.
</p>

<p>
  At the same time, I wanted to use the idea as an opportunity to put my React skills into practice by building a complete project rather than just working on small individual exercises.
</p>

<h2>About</h2>

<p>
  CINEVAULT is a movie discovery website I built while learning and improving my React skills.
  It allows users to browse movies, search for titles, check movie details, watch available
  trailers, explore recommendations, and save movies to their personal library.
</p>

<p>
  Instead of using hardcoded data, I used the TMDB API to work with real movie and TV show data.
  While building the project, I got to practice API integration, Redux, routing, Local Storage,
  responsive design, and a lot of debugging along the way.
</p>

<h2>Features</h2>

<ul>
  <li>Browse trending and popular movies</li>
  <li>Search for movies</li>
  <li>Discover movies and TV shows</li>
  <li>Filter by genre, year, rating, and popularity</li>
  <li>Watch available movie trailers</li>
  <li>View movie information and descriptions</li>
  <li>Explore recommended movies</li>
  <li>Add and remove movies from your library</li>
  <li>Save your library using Local Storage</li>
  <li>Responsive design for different screen sizes</li>
</ul>

<h2>Run Locally</h2>

<p>Clone the repository:</p>

<pre>
git clone https://github.com/rohankumarshah696/CineVault---Movie-Note
</pre>

<p>Move into the project directory:</p>

<pre>
cd CineVault---Movie-Note
</pre>

<p>Install the dependencies:</p>

<pre>
npm install
</pre>

<p>
  Create a <code>.env</code> file in the root directory and add your TMDB API key:
</p>

<pre>
VITE_TMDB_API_KEY=your_api_key
</pre>

<p>Start the development server:</p>

<pre>
npm run dev
</pre>
